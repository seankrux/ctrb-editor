# CTRBooster Editor V3

**New Single-File Editor: `ctrb_web_editor_v3.html`**

## 🚀 Key Features

### 1. ⚡ Client Wizard ("The Force Multiplier")
Automatically generate varied campaigns from a single client profile.
- **Input:** Client Name, URL, Keywords, Coordinates.
- **Output:** Creates multiple campaign types (GSearch, GMap, etc.) in one click.
- **Smart Jitter:** Automatically randomizes timing (e.g., 180s ±10%) so campaigns look human and unique.
- **Cluster Shifting:** Each variation gets a slightly different geolocation center point.

### 2. ⚡ Speed Editing
- **List View:** See all campaigns in a dense, Excel-like table.
- **Bulk Actions:** Select multiple campaigns -> Edit Timings / Daily Limits in bulk.
- **Clone:** One-click duplicate button for any campaign.

### 3. 🛡️ Safety
- **Validation:** Ensures all 72 fields are present.
- **Dark Mode:** Easy on the eyes for night work.
- **Zero Dependencies:** Just one HTML file. Runs anywhere.

## How to Use
1. Open `ctrb_web_editor_v3.html` in Chrome/Edge/Safari.
2. Go to **"⚡ Client Wizard"** tab.
3. Fill in the client details.
4. Select which types to generate (GSearch, GMap, etc.).
5. Click **"🚀 Generate Campaigns"**.
6. Go to **"Campaign List"** to see the results.
7. Click **"Import / Export"** -> **"💾 Save JSON"** to get your file for CTRBooster.
